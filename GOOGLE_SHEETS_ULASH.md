# Google Sheets ulash

1. Google Sheets'da yangi jadval oching.
2. Extensions → Apps Script ni bosing.
3. `Code.gs` ichidagi kodni shu papkadagi `Code.gs` bilan almashtiring.
4. Save qiling.
5. Deploy → New deployment → Web app.
6. Execute as: Me.
7. Who has access: Anyone.
8. Deploy qiling va berilgan Web app URL'ni nusxalang.
9. `index.html` ichidagi:
   `PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE`
   o‘rniga shu URL'ni qo‘ying.
10. Saytni qayta hostingga yuklang.

Forma yuborilganda `Buyurtmalar` nomli varaq yaratiladi va:
Sana | Ism | Telefon | Qulay vaqt
ustunlariga ma’lumot yoziladi.
